# Horror Mod

A terrifying Minecraft experience with custom blocks and weapons

## Features

- Custom block with interactive properties
- Custom sword with unique properties

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/horror-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric Loader installed.

## Usage

- Place the custom block in your world and interact with it.
- Craft or obtain the custom sword and use it in combat.
